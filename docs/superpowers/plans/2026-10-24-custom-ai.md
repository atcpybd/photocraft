# Custom AI Implementation Plan

> For agentic workers: use superpowers:executing-plans task by task.

Goal: portable native Windows build with API providers and ComfyUI, four AI operations and editable output.
Architecture: transplant reviewed upstream AI infrastructure onto v0.15.1, extend the provider registry and engine commands, reuse native settings/dialog/job infrastructure.
Tech stack: Rust, egui, ureq/rustls, Windows credential store, existing engine/control/MCP.
Spec: ../specs/2026-10-24-custom-ai-design.md

## Global constraints
Native Rust; preserve originals; one undo step per successful job; cancellable; no network at startup; secrets outside preferences; bounded image/network input; explicit automation opt-in; base v0.15.1; separate custom settings/branding.

## Review focus
- Stale jobs must never edit another document or layer.
- Invalid workflow links/mappings must fail before submitting.
- Errors and UI inspection must not expose credentials.
- Blend retains subject pixels in request; fill clears its hole.
- Cancel/failure during expand must leave canvas and layers unchanged.
